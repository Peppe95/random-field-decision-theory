# Local data

The source datasets are not stored in this repository.

Create local directories as needed:

```
data/raw/
data/processed/
```

Both paths are ignored by Git.

Download the original datasets from the sources in `../DATA_SOURCES.md`.

Participant-level preprocessing outputs should remain local unless their redistribution terms and privacy status have been checked explicitly. Small aggregate outputs used in the paper belong under `../results/`.
