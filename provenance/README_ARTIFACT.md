# RFDT dynamic-analysis numerical archive

This archive contains generated numerical material underlying the joint choice and response-time analyses reported in *Random Field Decision Theory: Deliberation through persistent and adaptive representations* by Giuseppe M. Ferro and Didier Sornette.

## Included artifact

`rfdt_guo_precision_for_manuscript_14177659.zip`

SHA-256:

`737500db81b9da24a46d05eea4c5864a3dd4ac494470ceb38b6a74cab168dc73`

The archive contains prediction tables, simulation summaries and numerical diagnostics from the corrected Guo analysis.

## Data

The original participant datasets are not redistributed in this deposit. They were collected by other research teams and should be obtained from the sources listed in the RFDT repository's `DATA_SOURCES.md`.

## Code

The corresponding source code and compact reproducibility materials are maintained at:

https://github.com/Peppe95/random-field-decision-theory
