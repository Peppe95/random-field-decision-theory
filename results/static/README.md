# Static result summaries

These files are compact derivatives of the frozen production outputs. They contain no raw or participant-level third-party data.

- `hab22_participant_benchmark_ranking.csv` — finite entries in the participant-generalization benchmark, excluding the separate pooled RFDT component-analysis specifications.
- `table_B1_hab22_selected_scores.csv` — manuscript Table B.1 values.
- `table_B2_static_restrictions.csv` — manuscript Table B.2 values.
- `choices13k_model_scores.csv` — external-validation model scores.
- `figure4_panel*.csv` — the only inputs needed by the static figure script.

The HAB22 participant-mixture MSE is 0.033102. The separate pooled RFDT-P MSE is 0.043691; these come from different fitting architectures.
Choices13k RFDT-P MSE is 0.014602 and power-EU MSE is 0.021647.
